# SimpleNote 📝

[Italian (README_IT.md)](README_IT.md) | [Russian (README_RU.md)](README_RU.md)

A minimal, native Android note-taking app that stays out of your way. Built using **Jetpack Compose** and **Material 3 Expressive**.

![Logo](app/src/main/res/drawable/app_logo.png)

I built this app to have a fast, clean place for Markdown notes. It follows modern Android practices like Clean Architecture and MVVM, but keeps the user interface playful and organic.

## What's inside

- **Pure Markdown**: No formatting bars or distractions. Just write.
- **Expressive Design**: Huge titles, extra-rounded corners, and smooth transitions.
- **Dynamic Color**: Adapts its theme based on your wallpaper (Android 12+).
- **Offline First**: Everything stays on your device using Room.
- **Fast Search**: Find what you need without waiting.

## The Tech
- **Kotlin** 100%
- **Jetpack Compose** (Material 3)
- **Hilt** for Dependency Injection
- **Room** for local persistence
- **Flow** based state management

## Getting Started
Just clone the repo and open it in the latest Android Studio. You'll need JDK 17.

```bash
git clone https://github.com/Elxes04/SimpleNote.git
```
