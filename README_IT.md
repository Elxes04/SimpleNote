# SimpleNote 📝

[English (README.md)](README.md) | [Russian (README_RU.md)](README_RU.md)

Un'app per note nativa e minimale per Android. Semplice e senza distrazioni. Sviluppata con **Jetpack Compose** e **Material 3 Expressive**.

![Logo](app/src/main/res/drawable/app_logo.png)

Ho creato quest'app per avere uno spazio veloce e pulito dove scrivere in Markdown. Segue le migliori pratiche moderne (Clean Architecture, MVVM), mantenendo un'interfaccia vivace e naturale.

## Funzionalità

- **Markdown Puro**: Niente barre di formattazione o distrazioni. Scrivi e basta.
- **Design Espressivo**: Titoli grandi, angoli molto arrotondati e transizioni fluide.
- **Colori Dinamici**: Si adatta ai colori del tuo sfondo (Android 12+).
- **Offline First**: Tutto rimane sul tuo dispositivo grazie a Room.
- **Ricerca Rapida**: Trova i tuoi pensieri all'istante.

## Tecnologie utilizzate
- **Kotlin** 100%
- **Jetpack Compose** (Material 3)
- **Hilt** per la Dependency Injection
- **Room** per la persistenza locale
- Gestione dello stato basata su **Flow**

## Come iniziare
Clona il repository e aprilo con l'ultima versione di Android Studio. È richiesto JDK 17.

```bash
git clone https://github.com/Elxes04/SimpleNote.git
```
