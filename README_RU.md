# SimpleNote 📝

[English (README.md)](README.md) | [Italian (README_IT.md)](README_IT.md)

Минималистичное нативное приложение для заметок на Android. Просто и без лишнего шума. Создано с использованием **Jetpack Compose** и **Material 3 Expressive**.

![Логотип](app/src/main/res/drawable/app_logo.png)

Я создал это приложение, чтобы иметь быстрое и чистое место для заметок в формате Markdown. Оно следует современным практикам разработки (Clean Architecture, MVVM), сохраняя при этом живой и органичный интерфейс.

## Особенности

- **Чистый Markdown**: Никаких панелей форматирования. Просто пишите.
- **Экспрессивный дизайн**: Крупные заголовки, сильно скругленные углы и плавная анимация.
- **Динамические цвета**: Адаптируется под цвета ваших обоев (Android 12+).
- **Offline First**: Все данные хранятся только на вашем устройстве через Room.
- **Быстрый поиск**: Находите свои мысли мгновенно.

## Стек технологий
- **100% Kotlin**
- **Jetpack Compose** (Material 3)
- **Hilt** для внедрения зависимостей
- **Room** для локального хранения
- Управление состоянием на базе **Flow**

## Как запустить
Клонируйте репозиторий и откройте его в последней версии Android Studio. Требуется JDK 17.

```bash
git clone https://github.com/Elxes04/SimpleNote.git
```
